# Human + AI Skills

The systems we install for small businesses, as free skills for your AI agent. Works with Claude Code, Codex, Cursor and other agents that read skills.

We cover AI for small business on the [Human + AI channel](https://www.youtube.com/@human_plusai) and build it into businesses at [humanai.news](https://humanai.news). These are the same playbooks we use on client work, written so you can run them yourself.

Every skill drafts by default. Nothing gets sent, published or posted without your yes.

## Install

Any agent:

```bash
npx skills add arcane-bear/humanai-skills
```

Claude Code plugin:

```
/plugin marketplace add arcane-bear/humanai-skills
/plugin install humanai@humanai-skills
```

Then start with `/discovery-prep` and the name of a business (yours or a client's).

## How we work

- **Drafts, not sends.** You approve everything that leaves your business.
- **No invented numbers.** Figures are sourced and dated, or labelled illustrative.
- **We say when to stay put.** If your current tool is fine, the skill says so.
- **Your accounts, your bills.** Skills set things up in accounts you own.

House rules for contributors are in [`_system/CONVENTIONS.md`](_system/CONVENTIONS.md).
